# Week 3 Structural Models

This folder contains the structural-modeling artefacts for the Study Planning Agent.

- `use-case-diagram.md` - system scope and external goals
- `class-diagram.md` - domain classes and relationships
- `object-diagram.md` - concrete runtime-like snapshot using the same values as `app.py`
- `database-diagram.md` - persistent entities, keys, and cardinalities
- `package-diagram.md` - logical package-level organization

The class and object views intentionally map to the Week 3 Python application.
